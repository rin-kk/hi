# Привет мир на C++ (Hello World)
Это простейший учебный проект на языке C++, демонстрирующий базовую структуру программы.

## Функционал
- Вывод текстового сообщения в консоль.
- Поддержка русского языка (корректное отображение кириллических символов без "кракозябр").

## Стек технологий
- Язык программирования: C++ (стандарт C++11 и выше)
- Среда разработки: Visual Studio / VS Code

## Сборка и запуск
1. Создайте "Пустой проект C++" (Empty Project).
2. Добавьте файл `main.cpp` и вставьте в него код.
3. Нажмите комбинацию клавиш `Ctrl + F5` для запуска.
